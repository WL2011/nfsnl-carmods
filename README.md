# NFSNL car mods

Files for the NFSNL car-mod installer app. The app reads `catalog.json` and downloads only the cars you choose.

- Install the app: [NFSNL-CarMods.apk](https://raw.githubusercontent.com/WL2011/nfsnl-carmods/main/NFSNL-CarMods.apk)
- Car files are named by content (`<md5>.pack` / `<md5>.cab`); the app checks every download.
